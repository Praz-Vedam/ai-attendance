# AI Attendance

Single documentation entry point: [docs/README.md](docs/README.md).

This repo contains:

- `backend/`: FastAPI attendance service, LMS integration, Redis-backed live sessions, face matching, anti-spoof and optional location review.
- `frontend/`: standalone Next.js demo/admin/student UI for local and Vercel deployments.
- `backend/load_tests/`: Locust load tests for LMS-integrated attendance routes.

Start with [docs/README.md](docs/README.md) for architecture, setup, API contracts, deployment, troubleshooting, and load-test operations.
